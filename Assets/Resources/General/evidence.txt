# Evidence/Profile

# You can define a new evidence/profile by adding its Id here
# By default, each entry will be linked with an icon of the same name, located in the Resources folder
# Evidence can also be associated with additional images, located in the defined Resources subfolder
# Evidence additional images have the format Evidence_ID_ImageNumber (Ex : Evidence_TestEvidence2_0)

# To add an evidence/profile, you can Write :
# Evidence ID [SpriteSheetName] [NumberOfAdditionalImages] [AdditionalImageSpriteSheet]
# Profile ID [SpriteSheetName]

# The relevant locals for evidences are :
# Evidence_ID_Name = The evidence's name
# Evidence_ID_Desc = The evidence's description
# Profile_ID_Name = The profile's name
# Profile_ID_Desc = The profile's description
